## 一、项目概况（2026-09-22 · v2.7.1）

**拾句**：Windows 桌面名言挂件。在桌面上安静展示一句好话（电影/游戏/小说/歌词/古诗词/名言/英文金句/编程语录/人生哲理，**共 2400+ 句**），支持换句动效、收藏、9 个大模型引擎翻译、分享图、定时关机、在线升级。

- **技术栈**：WPF / .NET 10（`net10.0-windows`）/ 零第三方 NuGet 依赖 / 单文件 exe 约 470KB
- **主工程**：`E:\Workspace_AI\ZCODE\demo_0820\QuoteWidget`
- **仓库**：https://github.com/Leon1734/shiju （公开；**源码不含任何 API Key**）
- **用户日常运行**：`QuoteWidget\bin\Release\net10.0-windows\win-x64\QuoteWidget.exe`
- **正式发布件**：`QuoteWidget\release\拾句_vX.Y.Z_便携版.zip`（含预配置智谱 Key，**只在本机，不进仓库**）
- **用户级技能**：`C:\Users\WDL\.agents\skills\shiju-widget\SKILL.md`（精简版手册；本文件是完整版）

## 五、标准工作流（SOP）

```bash
# ① 改代码前
taskkill //IM QuoteWidget.exe //F          # 否则构建报 MSB3021/3027 文件锁

# ② 构建（用户日常产物）
cd E:/Workspace_AI/ZCODE/demo_0820/QuoteWidget
dotnet build -c Release -r win-x64

# ③ 测试
cd tools/Tests && dotnet test               # 45/45

# ④ 重启（用户日常版本）
cd bin/Release/net10.0-windows/win-x64 && cmd /c "start QuoteWidget.exe"

# ⑤ 打包发布件（自动注入 zhipu.key → publish → 组装词库词典 → zip → 还原占位符）
cd tools/release && powershell -File make_portable.ps1 -Version "X.Y.Z"

# ⑥ 上传 GitHub Release（无 gh CLI，走 API；IP 需现场解析，见 SKILL.md）
#    发布件含预配置 Key → 只放本机 release/，仓库不含

# ⑦ 推代码（github.com:443 不稳，用仓库级 curloptResolve 指定可用 IP）
nslookup github.com 223.5.5.5               # 取候选 IP，逐个 curl --resolve 测 200
git config http.curloptResolve "github.com:443:<可用IP>"
git push origin main                        # 失败则用 tools/release/push_via_api.py（API 通道）
```

**推送注意**：本机 hosts 把 27 个 GitHub 域名拦到 127.0.0.1（含 api/uploads.github.com）；api.github.com 有稳定真实 IP 可直连，github.com:443 的 git 通道时好时坏——不通时用 `tools/release/push_via_api.py`（Git Data API 推送，含内容映射机制）。

## 六、踩坑清单（全部实锤，改代码前必读）

1. **WPF 下拉框绑元组显示空白**（踩了 3 次）——ItemsSource 一律用 record，DisplayMemberPath 用 nameof 且属性名必须对上
2. **`quotes.json` 字段小写**——反序列化必须 `PropertyNameCaseInsensitive=true`，否则内置词库全空（曾导致内置词库长期为空而不自知）
3. **WPF `Foreground = null` ≠ 恢复继承**——显式设置空画刷导致文字不可见；特效↔纯色切换必须 `ClearValue()`
4. **WPF Grid 越界行静默塞进最后一行**——加控件必须同步加 RowDefinition，否则与既有控件重叠
5. **PowerShell 5.1 读无 BOM 的 UTF-8 按 ANSI**——含中文的 .ps1 必须 UTF-8 带 BOM；读写用户文件用 `[System.IO.File]::ReadAllText/WriteAllText`
6. **批处理里 `timeout` 在隐藏控制台立即失败**——延时用 `ping -n N 127.0.0.1 >nul`；替换 exe 要带重试循环（文件锁未释放）
7. **升级包识别按内容魔数（PK/MZ）而非扩展名**——下载缓存无扩展名
8. **`SHQueryUserNotificationState` 的 QUNS_BUSY(2) 不可靠**——任务栏自动隐藏+最大化窗口会被误判为全屏；如需全屏判据用前台窗口矩形覆盖法（FullscreenWatcher 保留实现）
9. **"自动隐藏+自动恢复"类功能三铁律**：手动否决权、状态可见（菜单文案）、防抖；且**检测器不得因隐藏而停止**（否则恢复机制死锁）
10. **亚克力背景与 AllowsTransparency 互斥**——需非分层窗口，切换要重建窗口（`App.RecreateWidget()`，重建时解订阅+重挂热键）；亚克力下点击穿透主动禁用
11. **Python 脚本生成/修改 C# 源码时 `\n`/`\\` 转义曾两次写坏文件**——大改前先 git commit，坏了 `git show HEAD:<path>` 恢复
12. **发布 zip 含预置 Key**——绝不入库（.gitignore 已三层防护）；公开历史扫描确认 Key 从未泄露；Key 异常时去智谱后台重置
