# 拾句 · 桌面名言挂件

**在 Windows 桌面上，安静地展示一句好话。**

电影台词 · 游戏台词 · 小说名句 · 音乐歌词 · 古诗词 · 名人名言 · 英文金句 · 编程语录 · 人生哲理 —— 2400+ 句，还可联网补充「一言」、调用大模型翻译。

## ✨ 功能特性

### 🌈 好看的
- **七彩文字 / 渐变色 / 纯色**三种文字效果，出处与译文一并上色
- **壁纸亮度自适应**：全透明模式下按桌面明暗自动切换白字 / 墨字
- **流光卡片**：纯色 / 半透明卡片背景以双色渐变缓缓流转
- **淡出 → 淡入 + 上滑 + 微缩放**的换句动效，可选打字机逐字显示
- **主题预设**一键套用：墨夜 / 纸白 / 青瓷 / 樱粉 / 全透白字 / 全透墨字 / 智能跟随壁纸

### 🧠 好用的
- **定时自动换句**（5–300 秒可调），悬停自动暂停；也可手动切句、随机换句、每日一句
- **9 个翻译引擎**随时翻译当前句或任意文本：智谱 GLM-4-Flash（免费）/ 硅基流动 / DeepSeek / 通义千问 / Kimi / 讯飞星火 / 本地 Ollama / 离线词典 / 自定义端点
- **分享图生成**：把当前句子渲染成精美卡片 PNG，存图 + 复制一步到位
- **全局快捷键**：`Ctrl+Alt+Q` 换一句 · `Ctrl+Alt+F` 收藏 · `Ctrl+Alt+H` 显示/隐藏（可改键）
- **收藏夹**：标签管理、搜索筛选、导出 TXT / Markdown、双击定位原句
- **词库体检**：一键找出缺译文、重复句、空编号等问题并定位到文件行
- **贴心细节**：记住位置与设置、会话内不重复出句、勿扰时段、开机延迟启动、鼠标穿透、单实例

## 📦 安装

**方式一：下载便携版（推荐）**

从 [Releases](../../releases) 下载 `拾句_vX.X.X_便携版.zip`，解压后双击 `QuoteWidget.exe` 即可（需 .NET 10 桌面运行时）。

**方式二：自行构建**

```bash
git clone https://github.com/Leon1734/shiju.git
cd shiju/QuoteWidget
dotnet build -c Release -r win-x64
# 运行
./bin/Release/net10.0-windows/win-x64/QuoteWidget.exe
# 打包发布
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

## 📚 词库

内置 **2000+ 句**（电影 50 / 游戏 50 / 小说 50 / 歌词 50 / 古诗词 200 / 名人名言 200 / 英文金句 200 / 节日祝福 200 / 编程语录 200 / 人生哲理 200），全部以 **Markdown 文件**存放在程序目录 `词库\` 中——**用记事本就能增删改**，改完点"刷新词库"即生效。

`词库包/` 目录内附全部词库文件，可直接取用。

**添加自己的词库**：放入任意 `xx.md` / `xx.txt`，每个文件就是一个新分类，在设置里勾选开启。

```text
忙着活，或忙着死。——《肖申克的救赎》        ← 单行句，—— 后为出处
3. 人生就像一盒巧克力。——《阿甘正传》         ← 编号行也支持
1. Be yourself; everyone else is already taken.
   做你自己，因为别人都已经有人做了。—— 王尔德  ← 缩进行 = 多行句（英中对照）
```

详细规则见 [词库包/README.md](词库包/README.md)。程序还内置**词库体检**（设置 → 内容），自动发现缺译文、重复句等问题。

## 🌐 翻译引擎

| 引擎 | 费用 | 默认模型 | 说明 |
|---|---|---|---|
| 智谱 GLM-4-Flash | **免费** | glm-4-flash | 注册 [open.bigmodel.cn](https://open.bigmodel.cn) 获取 Key，翻译质量好，**推荐首选** |
| 本地 Ollama | 免费 · 离线 | qwen2.5:3b | 需自行安装 Ollama 并拉取模型，无需联网 |
| 硅基流动 | 有免费模型 | Qwen/Qwen2.5-7B-Instruct | 国内直连 |
| 通义千问 / 讯飞星火 | 有免费额度 | qwen-turbo / generalv3.5 | 注册后获取 Key |
| DeepSeek | 付费（约 2 元/百万输入） | deepseek-chat | 翻译一句成本约 0.001 元 |
| 离线词典 | 完全离线 | — | 单词查词（音标/词性/释义）+ 逐词直译，词条可自行扩充 |
| 自定义端点 | — | 自填 | 任意 OpenAI 兼容接口（本地模型、第三方网关均可） |

> 🔒 API Key 只保存在本机 `%APPDATA%\QuoteWidget\settings.json`，不上传到任何地方。源码中不含任何 Key，请自行填写。
