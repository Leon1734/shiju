# 词库使用说明

这个文件夹里的**每个 .md / .txt 文件就是一个分类**，挂件会自动加载。
修改文件后，到「托盘右键 → 设置 → 内容 → 刷新词库」即可生效（无需重启程序）。
（本 README 文件会被程序忽略，不会当作词库加载。）

## 内置分类（可直接编辑增补）

- `电影台词.md` / `游戏台词.md` / `小说名句.md` / `音乐歌词.md`
- 对应设置里的四个分类开关；删掉某个文件后重启程序会自动重新生成。

## 自定义分类

- 随便起名的文件（如 `英文好句.md`、`分类2.md`）就是新分类，
  在「设置 → 内容」的列表里可以单独勾选开关。

## 每句怎么写（三种写法可混用）

**① 单行句**（出处跟在 `——` 后面）：

```
忙着活，或忙着死。——《肖申克的救赎》
```

**② 编号行**（编号只是装饰，可要可不要）：

```
3. 人生就像一盒巧克力，你永远不知道下一块是什么味道。——《阿甘正传》
```

**③ 多行句**（适合"英文 + 中文翻译"：**缩进的行**并入上一句，
直到空行或下一个编号行才结束）：

```
1. Be yourself; everyone else is already taken.
   做你自己，因为别人都已经有人做了。—— 王尔德
```

显示效果：两行英文中文一起出现，出处"王尔德"在右下角。

## 规则速记

| 规则 | 说明 |
|---|---|
| 空行 | 分隔两句 |
| `#` 开头 / `---` | 标题和分隔线，会被忽略 |
| 编号行 `1.` `2、` | 一定开始新的一句 |
| **缩进的行**（行首有空格） | 并入上一句（多行句写法，如英文+中文翻译） |
| `——` | 句中遇到即视为出处开始（出处取**最后一个** `——` 之后的内容） |
| 连续多行都不带 `——` 也不缩进 | 上一行以句号/问号/感叹号等收尾则算两句，否则合并为一句 |
| `README` 开头的文件 | 程序忽略，不当词库 |

## 定时词库

在「设置 → 内容」里，每个词库（内置四个 + 自定义的）都可以单独设置生效时段：

- **全天**：一直参与换句
- **白天 8-22 点**：只在这个时间段出现
- **夜间 22-8 点**：只在这个时间段出现（适合睡前歌词包）

## 词库体检

「设置 → 内容 → 词库体检」会扫描本文件夹所有词库，检查：
缩进译文行缺主句、编号句缺译文（多行句写法的文件）、编号后没内容、
行内容重复、超长句。双击问题条目可用记事本打开对应文件修改。
