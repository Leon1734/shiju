1. Talk is cheap. Show me the code.
   空谈无益，放码过来。—— 林纳斯·托瓦兹
2. Simplicity is prerequisite for reliability.
   简单是可靠性的前提。—— 艾兹格·迪杰斯特拉
3. Premature optimization is the root of all evil.
   过早优化是万恶之源。—— 唐纳德·克努特
4. Programming is the art of telling another human what one wants the computer to do.
   编程是一门告诉另一个人你想让计算机做什么的艺术。—— 唐纳德·克努特
5. Any fool can write code that a computer can understand. Good programmers write code that humans can understand.
   任何傻瓜都能写出计算机能懂的代码，好程序员写的是人能懂的代码。—— 马丁·福勒
6. First, solve the problem. Then, write the code.
   先解决问题，再写代码。—— 约翰·约翰逊
7. Make it work, make it right, make it fast.
   先让它跑起来，再让它对，最后让它快。—— 肯特·贝克
8. Code is like humor. When you have to explain it, it's bad.
   代码就像笑话：需要解释就说明它烂。—— 科里·豪斯
9. The best error message is the one that never shows up.
   最好的错误提示，是永远不出现的那个。—— 托马斯·富克斯
10. Deleted code is debugged code.
    删掉的代码就是调试好的代码。—— 杰夫·西克尔
