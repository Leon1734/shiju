# 节日祝福（扩展包 · 节日彩蛋当天会优先展示本包句子）
# 春节
1. 新年快乐！愿你所求皆如愿，所行化坦途。—— 春节
2. 爆竹声中一岁除，春风送暖入屠苏。——王安石《元日》
3. 愿新的一年：不负时光，不负自己。—— 春节
4. 万事如意，阖家团圆，岁岁常欢愉，年年皆胜意。—— 春节
5. 一年忧喜今宵过，两鬓风霜明日新。—— 除夕
6. 千门万户曈曈日，总把新桃换旧符。——王安石《元日》
# 元宵节
7. 月色灯山满帝都，香车宝盖隘通衢。——李商隐《观灯乐行》
8. 火树银花合，星桥铁锁开。——苏味道《正月十五夜》
9. 愿灯火可亲，团圆有味，元宵安康。—— 元宵节
# 情人节
10. 愿天下有情人终成眷属，相伴一生。—— 情人节
11. 山有木兮木有枝，心悦君兮君不知。——《越人歌》
12. 玫瑰与晚风皆温柔，愿你被这世界温柔以待。—— 情人节
# 妇女节
13. 愿你眼里有光，心中有爱，活成自己喜欢的模样。—— 妇女节
14. 她们是母亲、是女儿、是自己，致敬每一位了不起的她。—— 妇女节
# 清明节
15. 清明时节雨纷纷，路上行人欲断魂。——杜牧《清明》
16. 慎终追远，不忘来处。—— 清明节
# 劳动节
17. 人世间的一切幸福，都要靠辛勤的劳动来创造。—— 劳动节
18. 愿所有的辛勤，都有回响；所有的付出，皆有收获。—— 劳动节
# 青年节
19. 愿中国青年都摆脱冷气，只是向上走。——鲁迅
20. 青春由磨砺而出彩，人生因奋斗而升华。—— 青年节
# 母亲节
21. 谁言寸草心，报得三春晖。——孟郊《游子吟》
22. 愿时光温柔，慢一点，让妈妈慢一点变老。—— 母亲节
# 儿童节
23. 愿你走出半生，归来仍是少年。—— 儿童节
24. 保持一颗童心，看什么都可爱。—— 儿童节
# 端午节
25. 粽叶飘香，龙舟竞渡，端午安康。—— 端午节
26. 路漫漫其修远兮，吾将上下而求索。——屈原《离骚》
# 父亲节
27. 父爱如山，沉默却厚重。愿天下父亲安康顺遂。—— 父亲节
# 教师节
28. 春蚕到死丝方尽，蜡炬成灰泪始干。——李商隐《无题》
29. 三尺讲台系国运，一生秉烛铸民魂。老师，您辛苦了。—— 教师节
# 中秋节
30. 但愿人长久，千里共婵娟。——苏轼《水调歌头》
31. 海上生明月，天涯共此时。——张九龄《望月怀远》
32. 月圆人团圆，愿所有的思念都有着落。—— 中秋节
# 国庆节
33. 山河远阔，国泰民安；愿以吾辈之青春，护卫盛世之中华。—— 国庆节
34. 此生无悔入华夏，家国同庆共此时。—— 国庆节
# 重阳节
35. 遥知兄弟登高处，遍插茱萸少一人。——王维《九月九日忆山东兄弟》
36. 愿家中长辈身体康健，岁岁重阳，今又重阳。—— 重阳节
# 圣诞节
37. 愿你的圣诞夜有灯火、有温暖、有所爱之人。—— 圣诞节
38. 铃儿响叮当，愿好运常伴你身旁。—— 圣诞节
# 冬至
39. 冬至阳生春又来，愿所有等待都不被辜负。—— 冬至
40. 白昼最短，思念最长，愿你三冬暖，愿你春不寒。—— 冬至
41. 新年钟声里，愿好运如约而至。—— 春节
42. 岁岁常欢愉，万事皆胜意；年年皆平安，日日皆晴天。—— 春节
43. 福启新岁，万事顺遂，平安喜乐得偿所愿。—— 春节
44. 愿新年：有盼头，有奔头，有甜头。—— 春节
45. 一元复始，万象更新；山河无恙，人间皆安。—— 元旦
46. 新年新气象，愿所有的遗憾都是成全。—— 元旦
47. 跨过昨天的坎，迎来明天的光。—— 元旦
48. 正月十五闹花灯，愿你的日子红红火火。—— 元宵节
49. 吃一碗汤圆，愿新的一年圆圆满满。—— 元宵节
50. 灯月交辉，人间团圆。—— 元宵节
51. 二月二，龙抬头，抬起一年好兆头。—— 龙抬头

53. 愿有情人终成眷属，愿相爱的人相守到老。—— 情人节
54. 世间万般美好，不及你回眸一笑。—— 情人节
55. 爱意东升西落，浪漫至死不渝。—— 情人节
56. 最好的爱情是：并肩看世界的两个人。—— 情人节
57. 致每一位了不起的她：愿妳被岁月温柔以待。—— 妇女节

59. 春天因你而美丽，世界因你而温暖。—— 妇女节
60. 种下一棵树，收获一片荫；种下善念，收获一生心安。—— 植树节

62. 清明祭故人，春光慰生者；愿逝者安息，生者坚强。—— 清明节
63. 梨花风起正清明，游子寻春半出城。——吴惟信《苏堤清明即事》
64. 缅怀是为了记得，记得是为了更好地前行。—— 清明节
65. 劳动创造美好，奋斗成就人生；节日快乐，劳动者！—— 劳动节
66. 愿你的每一份辛苦，都有人看见、有回报。—— 劳动节
67. 放下工作，好好休息，是为了走更远的路。—— 劳动节
68. 五四薪火，代代相传；愿你眼里有光，心中有火。—— 青年节
69. 年轻不是年龄，而是敢于做梦的勇气。—— 青年节
70. 愿你出走半生，归来仍是少年。—— 青年节
71. 愿天下母亲：眉目舒展，笑靥如花，健康长伴。—— 母亲节

73. 你陪我长大，我陪你变老。—— 母亲节
74. 一句妈妈，是世界上最温柔的呼唤。—— 母亲节
